# 💬 초간단 AI 단톡방

열쇠가 있는 사람만 들어오는 **나만의 비밀 AI 단톡방**이에요.
제미나이·지피티·클로드를 원하는 만큼 켜서 **각자 역할을 나눠 일 시키고**, 카카오톡처럼 대화할 수 있어요.
같은 AI라도 **이름과 역할을 다르게 여러 명** 넣을 수 있어요. (예: 제미나이1호·제미나이2호)
어려운 프로그램 없이 파일 몇 개만 인터넷에 올리면 바로 쓸 수 있어요.

---

## 1. 3분 만에 시작하기

1. 앱 주소를 열면 **🔒 입장 키가 필요해요** 화면이 나와요.
2. **새 비밀 방 만들기**를 누르면 나만의 비밀 방 주소가 만들어져요.
3. 오른쪽 위 **⚙️** → **AI 열쇠(API 키)** 칸에 열쇠를 붙여 넣고 → **저장**.
4. 아래에 하고 싶은 말을 쓰고 **전송**을 누르면 AI들이 차례로 대답해요.

> 🔗 버튼을 누르면 **비밀 초대 링크**가 복사돼요. 나만 쓸 거면 아무한테도 보내지 않으면 돼요.
> 링크를 잃어버리면 그 방의 대화는 다시 못 열어요. 꼭 안전한 곳에 저장해 두세요.

---

## 2. 역할 나누기 (각자 일하게 하기)

⚙️ 설정에서 AI마다 **이름**과 **담당 역할**을 적어 줄 수 있어요. 예를 들면:

| AI | 이름 | 담당 역할 |
|---|---|---|
| Gemini | 제미나이 | 블로그 원고 담당 |
| ChatGPT | 지피티 | 스레드 카피·아이디어 담당 |
| Claude | 클로드 | 최종 검수·실행 담당 |

- **전체 (각자 역할대로)** 에게 말하면, 켜 둔 AI가 **한 명씩 차례로** 답해요.
  앞사람 답변을 읽고 **자기 역할에서 보탤 것만** 말해요. (같은 말 반복 금지)
- 본문에 **@제미나이** 처럼 이름을 직접 써서 보내면 **그 AI만** 불러요. 나머지는 답하지 않아요.
- 말풍선 이름 옆에 항상 `제미나이 · 블로그 원고 담당` 처럼 역할이 붙어 있어요.

### AI 친구 추가·삭제 (원하는 만큼)

⚙️ 설정 → **AI 친구들** 아래 **＋ AI 친구 추가** 를 누르면 새 AI를 넣을 수 있어요.

- **이름**은 `@`로 부를 이름이에요. 공백도 넣을 수 있어요. (예: `유튜브1호`, `제미나이 2`)
- **종류**는 Gemini / ChatGPT / Claude 중에서 골라요.
- **같은 종류를 여러 명** 넣을 수 있어요. 예를 들어 Gemini 두 명을 `제미나이1호`(유튜브 대본 담당), `제미나이2호`(블로그 원고 담당)로 나눠 쓸 수 있어요.
- 새 AI의 열쇠는 **같은 종류 AI의 열쇠를 자동으로 채워 줘요.** (비어 있으면 직접 붙여 넣으면 돼요.)
- 카드 오른쪽 위 **✕** 로 AI를 뺄 수 있어요. 기본 3명도 지울 수 있고, **최소 한 명**은 남겨 둬야 해요.
- 이름이 겹치면 저장할 때 뒤에 번호를 붙여 서로 구분해요.
- 추가·삭제·이름 변경은 **저장**을 눌러야 반영돼요. 상단 배지·역할 한눈에 보기·`@` 칩·전체 순차 응답이 모두 바뀐 목록 그대로 움직여요.

## 3. AI 열쇠(API 키) 받는 곳

| AI | 받는 곳 | 참고 |
|---|---|---|
| 제미나이 | <https://aistudio.google.com/apikey> | 구글 아이디로 무료로 받을 수 있어요 |
| 지피티 | <https://platform.openai.com/api-keys> | 카드 등록이 필요하고, 쓴 만큼 돈이 나가요 |
| 클로드 | <https://console.anthropic.com/settings/keys> | 카드 등록이 필요하고, 쓴 만큼 돈이 나가요 |

- 열쇠는 **이 기기(브라우저)에만** 저장되고, 초대 링크나 공용 공책으로는 **절대 나가지 않아요**.
- 열쇠가 없거나 틀리면 그 AI가 **친절하게 안내 말풍선**을 띄워요.

## 5. 인터넷에 올리기 (GitHub Pages, 무료)

이 폴더(`ai-groupchat`) 안의 파일을 그대로 올리면 돼요.

1. <https://github.com/new> 에서 새 저장소를 만들어요. 이름 예: `ai-groupchat`, **Public** 선택.
2. **uploading an existing file** 을 눌러 이 폴더의 파일 전부를 올려요.
   (`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `icons/` 폴더, `README.md`)
3. 저장소 **Settings → Pages** → Source 를 `Deploy from a branch` → Branch `main` / `(root)` → **Save**.
4. 1~2분 뒤 `https://내아이디.github.io/ai-groupchat/` 로 열려요. 이 주소를 폰에 저장해 두세요.

> 저장소를 새로 만들 때는 **방을 먼저 만든 뒤** 나온 비밀 링크를 즐겨찾기/메모에 저장해 두면 편해요.

## 6. 폰과 PC에서 같은 대화 보기 (공용 공책, 선택)

기본은 **이 기기에만** 저장돼요. 폰·PC·다른 사람과 같이 보려면 무료 공용 공책(Firebase Realtime Database)을 하나 붙이면 돼요.

1. <https://console.firebase.google.com/> 에 구글 아이디로 로그인 → 새 프로젝트 만들기.
2. 왼쪽 메뉴 **Realtime Database** → **만들기** → 위에 나오는 주소(`https://....firebasedatabase.app`)를 복사.
3. 그 주소 끝에 `/rooms.json` 을 붙여 열고, 규칙(rules)을 아래처럼 바꿔 저장해요.

```json
{
  "rules": {
    "rooms": {
      "$room": {
        "messages": {
          ".read": true,
          ".write": true
        }
      }
    }
  }
}
```

4. ⚙️ 설정의 **공용 공책** 칸에 주소를 붙여 넣고 저장 → 3초마다 새 대화를 확인해요.

- 대화는 `rooms/방이름_비밀열쇠/messages` 자리에만 저장돼요. 열쇠를 모르면 그 자리를 찾을 수 없어요.
- 공용 공책에 올라간 대화는 **링크를 아는 사람이면 볼 수 있으니** 비밀 이야기는 넣지 마세요.

---

## 7. 잠금 규칙 (중요)

- 주소에 `?room=...&k=...` (비밀 열쇠)가 **둘 다 있어야만** 채팅 화면이 열려요. 없으면 잠금 화면만 보여요.
- 열쇠는 16자 이상의 무작위 값이고, 방마다 달라요.
- 기기 저장소도 `방이름_열쇠`로 나뉘어 있어서, 열쇠가 다르면 기존 대화에 접근할 수 없어요.
- 초대 링크를 아무 데나 올리지 마세요. 링크를 가진 사람은 이 방을 열 수 있어요.
