새 AI 친구

공용 공책 기본 연결됨

폰이랑 PC에서 같은 대화를 보려면 공용 공책 주소가 필요해요. 기본 공용 공책이 미리 연결돼 있으니 그냥 저장하면 되고, 내 Firebase 주소로 바꿔도 돼요. 칸을 비우고 저장하면 이 기기에만 저장돼요.

공용 공책은 어떻게 만들어요?
  1. Firebase에 구글 아이디로 로그인해요.
  2. 새 프로젝트를 하나 만들고, 왼쪽 메뉴에서 Realtime Database를 눌러 만들기를 골라요.
  3. 위에 나오는 주소(https://....firebasedatabase.app 또는 ....firebaseio.com)를 복사해요.
  4. 그 주소 끝에 /rooms.json을 붙여 열고, 규칙(rules)을 아래처럼 바꿔 저장해요. 
    {
  "rules": {
    "rooms": {
      "$room": {
        "messages": {
          ".read": true,
          ".write": true
        }
      }
    }
  }
}
  5. 주소를 위 칸에 붙여 넣고 저장하면 끝! 이제 초대 링크 하나로 대화가 같이 보여요.

※ 공용 공책에 넣은 대화는 링크를 아는 사람이면 볼 수 있으니, 비밀 이야기는 넣지 마세요. 대화는 이 방의 비밀 열쇠로 잠근 자리에만 저장돼요.
